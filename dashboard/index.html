Common commands

Sites

site add <name>
Serve sites/<name> at https://<name>.{{NOVACORE_TLD}}
site info <name>
URL, paths and DB settings
site rm <name>
Stop serving (files kept)
open [site]
Open in your browser

PHP

php <site> X.Y
Switch a site's PHP version
xdebug on|off
Toggle Xdebug
shell [site]
Bash in the PHP container
wp|composer <site> …
Run WP-CLI or Composer

Databases

db list
List databases
db import <db> <file>
Load a .sql or .sql.gz
db export <db>
Dump to .sql.gz
db shell [db]
MariaDB console

Debugging

errors [site]
Follow PHP error logs
logs [service]
Follow container logs
status
Containers and sites
trust
Fix certificate warnings
Config lives in .env and sites.conf; apply changes with novacore reload.
